# Paint con Flechas del Teclado

Una aplicación interactiva de dibujo (paint) controlada con las flechas del teclado.

## Características

- 🎨 Dibujo en lienzo (canvas HTML5)
- ⌨️ Control con flechas del teclado para mover el cursor
- 🖱️ Soporte de ratón para dibujar
- 🎯 Selector de color personalizable
- 📏 Ajuste del tamaño del pincel
- 💾 Descarga de dibujos en PNG
- 🧹 Botón para limpiar el lienzo

## Cómo Usar

1. Abre el archivo `index.html` en tu navegador
2. Usa las **flechas del teclado** para mover el cursor
3. Presiona **Espacio** para activar/desactivar el modo dibujo
4. También puedes hacer clic y arrastrar con el ratón para dibujar

## Controles

- **Flechas (↑ ↓ ← →)**: Mover el pincel
- **Espacio**: Activar/desactivar dibujo automático
- **Clic y arrastrar**: Dibujar con el ratón
- **Color**: Selector de color para cambiar el color del pincel
- **Tamaño**: Deslizador para ajustar el grosor del pincel
- **Limpiar**: Vaciar el lienzo
- **Descargar**: Guardar el dibujo como imagen PNG

## Tecnologías

- HTML5 Canvas
- CSS3
- JavaScript Vanilla
